Importar deck externo via URL
Cole a URL de um arquivo JSON público. O arquivo será validado antes de ser importado — scripts, HTML e campos maliciosos são rejeitados automaticamente.

Segurança: apenas HTTPS é aceito · máx 500 KB · somente JSON · campos limitados a texto simples · sem execução de código

Formato esperado do JSON
{ "name": "Meu Deck", "icon": "📚", "cards": [ { "f": "Hello", "b": "Olá", "r": "opcional", "ex": "Hello world" }, { "f": "Bye", "b": "Tchau" } ] }

Onde encontrar decks JSON gratuitos:

· GitHub Gists com decks da comunidade
· Pastebin (use links raw)
· Seu próprio servidor ou GitHub Pages
· Ferramentas como Anki exportam para formatos convertíveis
